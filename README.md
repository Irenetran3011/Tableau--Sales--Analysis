# 📊 Tableau Sales Analysis Dashboard

## Overview

This project presents an interactive Tableau dashboard built using the Global Superstore dataset. The dashboard provides insights into sales, profit, regional performance, customer segments, and product categories to support business decision-making.

## Dashboard Preview

![Dashboard](dash board.png)

---

## Objectives

- Analyze sales performance
- Identify the most profitable regions
- Compare product categories
- Explore customer segments
- Discover business trends

---

## Tools Used

- Tableau
- Microsoft Excel
- GitHub

---

## Dataset

Global Superstore Dataset

---

## Key Insights

- West region generated the highest sales.
- Technology was the most profitable category.
- Consumer customers contributed the largest share of revenue.
- Some regions had strong sales but low profitability.
